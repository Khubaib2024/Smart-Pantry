Smart Pantry 🍽️
![Untitled design](https://github.com/user-attachments/assets/bdfce937-fe81-46eb-aab7-a1b736e58fff)

Smart Pantry is a web-based application designed to revolutionize kitchen management by helping users efficiently track pantry items, reduce food waste, and discover delicious recipes based on available ingredients. With features like expiration alerts, voice recognition, and a shopping list generator, Smart Pantry makes kitchen management effortless and enjoyable.

🚀 Features
1. Inventory Management
Easily log and monitor pantry items.

Categorize items for better organization (e.g., grains, spices, dairy).

Track quantities and update inventory in real-time.

2. Recipe Suggestions
Get personalized recipe recommendations based on the ingredients you have.

Filter recipes by dietary preferences, cuisine, or cooking time.

3. Expiration Alerts
Receive timely notifications for items nearing their expiration dates.

Minimize food waste by staying informed about your pantry.

4. Shopping List Generator
Automatically generate a shopping list for missing ingredients in your desired recipes.

Simplify grocery shopping and ensure you never run out of essentials.

5. Voice Recognition
Update your pantry inventory using voice commands for a hands-free experience.

Compatible with popular voice assistants for seamless integration.

🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js )

Database: MySQl database system
